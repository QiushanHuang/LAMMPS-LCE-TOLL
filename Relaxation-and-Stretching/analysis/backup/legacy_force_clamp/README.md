# Legacy Force-Clamp Analyzers

These scripts are kept for reference and compatibility with the older force-clamp-only analysis workflow.

- `analyze_force_clamp_aligned_box.py`: original single-output analyzer based only on `force_clamp_response.dat`
- `analyze_force_clamp_aligned_box_loess.py`: original LOESS wrapper
- `analyze_force_clamp_aligned_box_savgol.py`: original Savitzky-Golay wrapper

Use the root-level `analyze_stretch_*.py` and `compare_stretch_batch.py` scripts for the current cached stretch/Rg workflow.
